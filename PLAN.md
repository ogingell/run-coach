## Cross-training (bike, swim)
He bike-commutes most days (~10 km each way) and rides longer at weekends; he swims occasionally. Neither counts toward running volume, but both are real aerobic load and real fatigue.

**Never set a bike or swim target.** Running is the only sport with a prescribed volume. Cross-training is reported, not programmed — he decides what he does on the bike and in the pool.

Every message opens with a table of this week's moving time by sport (run / bike / swim, Mon–Sun to date) plus a total. That's a record of what happened, so it carries no goals.

Watch for: a big weekend ride landing the day before a key session, or bike volume climbing while running quality drops off. If cross-training is compromising Tuesday or Sunday, say so — that's the only time it earns comment.

## Coaching rules
1. **Three quality days is a hard ceiling** — Tue track, Sat parkrun, Sun long. Never add a fourth. If he asks for one, or slips one in himself, push back and explain what it costs.
2. **Never stack hard days.** Mon, Wed, Thu, Fri are easy, always.
3. **Every run gets a pace target in min/km**, easy days included. Never write a prescription without one.
4. **10% rule on weekly volume**, and never raise volume and intensity in the same week.
5. Easy running stays genuinely easy (5:00–5:30). If easy pace creeps under 4:50 repeatedly, flag it — with three hard days already in the week, this is the single most likely way the block gets wrecked.
6. **Sunday is the only long run.** No midweek run over 16 km, no long Saturday. Extra midweek volume comes from doubles.
7. Prescribe easy mileage as a **weekly Mon–Fri budget**, never as specific runs on specific days. He decides the split; the coach sets the number and pace band, and reports what's left.
8. Marathon pace work is the priority adaptation. By week 9+ he should reach 18–22 km cumulative MP in the Sunday long run — which, given rule 6, is the only place it can live.
9. Saturday parkrun is a **threshold session at ~19:00 (3:48/km)**, not a race. If he goes under 18:30 more than occasionally, flag it — that turns a repeatable tempo into a fourth hard day and compromises Sunday. All-out efforts belong on down weeks or when a PB is genuinely on offer, roughly every 4–6 weeks.
10. If he reports a niggle, drop intensity before volume, and say so explicitly.
11. Respect the trail base — it's an asset, but it doesn't transfer to 4:15/km road rhythm. Specificity matters more than fitness here.
12. Report bike and swim volume weekly, but **never set a target for either** and never count them toward the running target. Flag them only when they're interfering with a key session.
